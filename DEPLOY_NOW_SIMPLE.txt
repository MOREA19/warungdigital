📋 DEPLOY SEKARANG - STEP BY STEP SIMPLE

==================================================
STEP 1: BUKA SUPABASE DASHBOARD
==================================================

https://supabase.com/dashboard/project/etvwxarauhbutuxrjqpf/functions

(Login jika perlu dengan akun Supabase kamu)


==================================================
STEP 2: KLIK FUNCTION "server" DI LIST
==================================================

Di sebelah kiri ada list functions.
Cari yang namanya: "server"
KLIK untuk membuka.


==================================================
STEP 3: CLEAR EXISTING CODE
==================================================

Di editor code Supabase:
- Tekan: Ctrl+A (select all)
- Tekan: Delete (hapus)

Sekarang editornya kosong.


==================================================
STEP 4: COPY CODE DARI PROJECT
==================================================

Di VS Code kamu:
1. Buka file: src/supabase/functions/server/index.tsx
2. Tekan: Ctrl+A (select all)
3. Tekan: Ctrl+C (copy)


==================================================
STEP 5: PASTE KE SUPABASE EDITOR
==================================================

Di browser, di Supabase editor kosong:
1. Tekan: Ctrl+V (paste)

Tunggu code selesai paste.


==================================================
STEP 6: DEPLOY
==================================================

Di bottom-right corner editor, ada tombol: "Deploy"
KLIK tombol itu.

Tunggu sampai status berubah jadi:
"Active" (HIJAU)

Ini akan memakan waktu 10-30 detik.


==================================================
STEP 7: VERIFIKASI
==================================================

Setelah status "Active", buka terminal VS Code:

npm run dev

Tunggu sampai:
"VITE vX.X.X ready in XXX ms"
"Local: http://localhost:3000"

Kemudian:
1. Buka browser: http://localhost:3000
2. Login: admin@arkan.com / admin123
3. Masuk: "Manajemen Pelanggan"
4. SEHARUSNYA MUNCUL 2 CUSTOMERS: Budi & Siti


==================================================
JIKA BERHASIL ✅
==================================================

- Customers muncul di Admin Panel ✓
- Bisa buat customer baru via Register ✓
- Bisa login dengan customer ✓
- Dashboard bekerja ✓
- SIAP DIPRODUKSI!


==================================================
JIKA MASIH ERROR ❌
==================================================

1. Cek Supabase dashboard:
   - Apakah function status = "Active"?
   - Jika tidak, ulangi STEP 3-6

2. Cek browser console (F12):
   - Ada error apa?
   - Lihat network tab
   - Lihat response dari API

3. Cek edge function logs di Supabase:
   - Dashboard > Edge Functions > server
   - Tab "Invocations"
   - Lihat error details


==================================================
SIAP UNTUK PRODUCTION?
==================================================

Setelah ✅ di-deploy dan tested:

npm run build

Folder "build/" sudah siap untuk di-host.

Upload ke:
- Vercel (drag-drop)
- Netlify (drag-drop)
- Server sendiri (SCP/FTP)
- Cloud hosting lainnya
